2The principle: no boxes Your question, written as five rules. This section follows them itself.
Content sits on the page.Nothing is wrapped in a card. A match, a list and a table all lie on the same surface.
A black rule starts a section.One thin black line and a small label: Next, Earlier, a map, the standings.
A hairline separates rows.Inside a section, rows are divided by the faintest line, never by gaps between boxes.
Space and size set the order.The live match comes first and is set largest. It needs no frame to be the most important thing on the screen.
Only what floats or is pressed gets a shape.The navigation, a text field, the selected day, a team's disc. Everything else is type, dots and lines.
